#Personial Task Manager
## Description
A simple task manager built using python. It allows user to add,view,mark completed task, and delete tasks.
Tasks are saved in text file so they are available whenever we need , or when the program is start.
### Features
Add tasks
view all tasks
mark tasks as completed
delete tasks
save task in text files
## Technologies used
- python
- File Handling
- Git
- GitHub
